JavaScript 语法检查和离线 mock 通过，覆盖分页循环/页数上限/未知结构/总数不符、同源限制、下载范围与显式保存。额外使用合成 1 秒 WAV 验证了 ffprobe 音轨与时长分支；没有 ffprobe 的较弱验证路径另有测试。
