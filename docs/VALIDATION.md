本次没有重新全量测试论坛、阅读清单、全部分页或新的无字幕音频下载。音频回退流程来自前一轮实际归档经验，本包的本地音频分支通过下列合成测试及 ffprobe 检查。可选 localhost 桥接仅做本机测试；此次真实浏览器采用宿主支持的 UI/DOM、网络响应读取和本地文件传递，没有在受限 evaluate 中执行 fetch。

真实样本和认证数据没有打入公开仓库。主张限于“这些采集与本地整理步骤已跑通”，不是全课重新完成，也不是其他浏览器已验证。

## 本地工具测试

41 项 Python 测试全部通过：

- 录播整理 13 项：VTT/SRT/TXT/DOM 时间戳、中文与说话人、原字节保留、同名不同场次、多片段、明确覆盖确认、增量 inventory、幂等、冲突、部分范围/HTML/空文件拒绝、缺少 ffprobe、文件篡改及 CLI 退出码。
- 材料接收器 7 项：精确来源/Host/令牌、本机预检、幂等与不覆盖、路径和 symlink、大小/部分请求、关停与临时令牌清理。
- 总索引 21 项：材料/录播单模块与合并、缺项 pending、哈希与零字节、未知/重复身份、not_available 理由、路径越界、来源 URL 去查询参数、录播虚假 complete 标志不能掩盖缺项。

JavaScript 语法检查和离线 mock 通过，覆盖分页循环/页数上限/未知结构/总数不符、同源限制、下载范围与显式保存。额外使用合成 1 秒 WAV 验证了 ffprobe 音轨与时长分支；没有 ffprobe 的较弱验证路径另有测试。

录播模块另由一位独立代理只依据包内说明试用：同名多场、两段字幕、无 ffprobe 音频、最后盘点新增 blocked 场次均正确处理，旧文件哈希保持不变。整包经过独立文档审阅。
