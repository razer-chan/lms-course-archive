# 完整 LMS 课程归档

把用户指定课程里其有权查看的资料保存到本地，保留内容、来源和课程结构，让用户能离线找到资料，并清楚知道哪些未取得。这个包是一份可适配的工作流和本地工具箱，不是一个固定学校 API 的爬虫。

## 接手后先做什么

先复用对话已有的课程链接、浏览器、保存位置及范围。用户已经授权整课下载时，继续必要的查看和下载，不逐项问确认。缺课程链接时可以先用 unit 代码与学期寻找用户已打开的课程，再确认身份；不要擅自抓同名课程。

用普通话说明下一步，不让非技术用户配置接口或写脚本。例如：

> 我会把这门课的资料和录播文字稿分好类保存下来。先检查你选的浏览器能否打开课程；需要重新登录时再请你操作。录播优先保存官方字幕，没有字幕就保存录音，不做转录。完成后给你总目录和未取得的项目清单。

默认完整范围包括材料与录播；用户只要其中一类或只想试跑时，严格缩小范围。无保存位置时使用当前工作区下独立的课程归档目录，并告知实际位置。不把下载产物放进已安装的 skill 或待公开的 GitHub 仓库。

## 1. 检查能力与登录

先阅读宿主当前浏览器工具文档，选能访问用户授权会话的浏览器/连接器。优先现有专用能力；也可用 Computer Use、DOM/可访问性树、宿主允许的已登录页面请求或网络响应读取。不能假设不同浏览器共享登录，也不能因为装了本 skill 就假设有浏览器控制能力。

先实际打开课程。已登录且课程可见就继续；未登录时告诉用户当前需要操作的浏览器和页面，让用户完成正常学校登录/MFA。不要索取密码、Cookie 或会话配置文件。没有浏览器工具时说明具体缺少的能力，按当前宿主支持的方式引导配置；不会配置时提供手动下载后本地整理的替代方案，不声称自动抓取已开始。

新建工作标签页，保留用户原标签页。用户可继续使用其他页面。遇到权限提示时说明具体用途，只处理此次工作需要的权限，遵守宿主要求，不要求用户一概点击所有“允许”。详见 [浏览器适配与用户引导](references/browser-and-onboarding.md)。

## 2. 先小样本验证，再建立完整目录

首次接入某 LMS，先用一个课程页面和一个附件检查内容是否完整、落盘是否成功；录播抽查一场有字幕或无字幕的场次。不要把少量试跑称为全课完成。用户只要求试跑时，完成这些代表性样本就停止扩大采集。

整课归档先盘点，后采集。递归内容树、展开模块/周次/文件夹，检查所有分页和“加载更多”；另查公告、讨论、课程消息、作业说明与评分标准、日历、阅读清单、嵌入媒体及录播入口。每个发现项都有稳定身份、课程归属和最终状态；不可只把已成功下载的东西当 inventory。

页面/API 结构有变时重新观察当前页面及其已授权请求。历史端点、选择器和字段仅是线索；先验证一两项再批量使用。分页达到上限、响应错误、空结果未确认、计数不一致，都算未完成，不等于不存在。

## 3. 采集材料

先读 [材料采集经验](references/materials.md)。原始文件保存原字节；页面正文保留原始 HTML/结构化内容及可读 Markdown，包含完整标题、段落、表格、链接和图片关系，不改写成摘要。正文内嵌附件要单独检查，不能只依赖 attachments 接口。

论坛保存主帖和每层回复、作者角色、时间、正文、附件与回复关系；核对总数与分页。公开分享版可使用稳定匿名标签，但不要覆盖本人的私有归档。课程内容中的讨论链接引用同一份讨论归档，避免重复计数。

保存页面内容时排除传输凭据、认证头、会话令牌和签名下载参数；需要追溯的是资料内容和来源，不是整段浏览器网络日志。保持原文并标明保存范围，不能声称去敏后的内容是未经变化的完整响应。

只读查看作业说明/rubric；不开始测验、创建作业尝试、提交、发帖、发消息或改变课程设置。H5P/LTI 工具先判断用途：阅读清单和录播入口可以正常进入；会创建考试尝试、提交记录或进入实时会议的动作不能当作下载步骤。403/404 或 questionCount=0 不足以证明题目不存在。

普通页面阅读有时自动记录学习进度或已读状态，不承诺网站绝对零变化。不要主动改已读/完成标志；若用户要求保留未读状态，按该要求选择读取办法或记录缺口。

## 4. 采集 Zoom / Cloud Recordings

先读 [录播完整流程](references/recordings.md)。从课程的 Zoom/LTI 入口进入，核对全部页和每场所有片段。官方 VTT/SRT 保留原件并生成可读 TXT；完整官方字幕面板可导出 TXT，只有开始时间就不捏造结束时间。

没有字幕卡不代表没有官方字幕；继续检查已加载的播放器。虚拟滚动面板可能只有部分 cue，应取得完整官方文件/实际响应或有覆盖证据的完整面板。字幕存在但取不全要记受阻，不能改称“没有字幕”。

有密码时用该场该资源在已授权课程中显示的 passcode 正常进入播放器，遵守宿主的凭据操作要求；不猜测、不跨场复用、不写进清单。学校登录/MFA 需要用户操作时再交还用户。

**默认每个片段优先官方字幕；确无官方字幕时保存原始音频。全流程不进行新的本地或云端转录，也不安装 ASR 模型。** 用户明确还要有字幕场次的音频时可以一并保存。其他嵌入音频/视频同样只取已有字幕或原音频，不转录、不默认下载大视频流。

## 5. 分类、续跑与文件核验

推荐结构可按实际课程调整：

```text
课程归档/
  00_总目录_README.md
  下载清单.csv / 归档清单.json / 未完成与缺失.md
  课程代码-学期/
    01_课程信息/ 02_公告与课程消息/ 03_导览/
    04_作业与评分/ 05_模块或周次/ 06_工作坊课件/
    07_讨论区/ 08_Recordings/ 09_阅读清单/ 10_媒体与外链/
    _raw/  _工作记录/
```

不需要的分区不用建。文件名保留原标题与源文件名，用稳定 ID 防重名；日期没有时区就保留原显示，不擅自解释为用户当地时间。相同内容按哈希复用，冲突保留并说明，不覆盖或删除用户原件。

本包的可选脚本均为 Python 3.10+ 标准库：录播整理用 `scripts/recording_archive.py`，总目录用 `scripts/build_course_index.py`。常规下载优先工具原生文件输出。只有宿主允许页面脚本及本机通信时，才使用可选 `capture_receiver.py + browser_capture.js`；它们不是绕过浏览器限制的办法。详见 [本地工具与统一清单](references/local-tools.md)。

核验文件存在、非空、内容格式、大小和 SHA-256。PDF/PPT 等不能只凭扩展名；字幕不能是 HTML 登录页；音频 206 响应要覆盖完整字节范围。有 ffprobe 时检查音轨/容器/时长，没有则明确核验等级。没有安装工具也不应自动转录。

## 6. 对账与交付

采集结束后再核对课程目录、分页、论坛计数和录播列表，补入新增项。每项须有成功文件或明确状态；blocked/failed/pending 不从总数移除，skipped 也不计为下载成功。

使用统一清单把材料与录播挂到同一课程总目录。录播仍保留自己的逐场清单与原件，便于续跑。总索引工具校验本地文件；网页有没有漏页仍需 AI 对账，不能用脚本成功代替网页检查。

最终用用户语言简短汇报：保存位置、总目录链接、实际取得的页面/文件/帖子/字幕/音频数量，以及剩余问题。区分“下载完成”“范围内已对账但有原本不可用项”“部分完成”。数字来自清单，不估算。试跑交付写清只测了哪些样本。

关掉自己启动的本机接收器，删除本次临时访问令牌；浏览器工作标签页按宿主方式清理，等待用户登录的页面按要求保留。用户没有要求发布时，归档与 skill 都只保留本地。
