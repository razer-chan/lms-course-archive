# 非录播资料：采集思路与实测线索

本模块整合了 2026-11 的 Blackboard Ultra / SCU 资料抓取经验。其目标是完整保存用户可访问的课程资料，方法可以替换。下面的接口不是永久承诺；优先从当前页面及其请求确认课程身份、访问权限、字段与分页，先小样本再批量。Canvas/Moodle 等平台可沿用目录、来源、分页、回复树与校验思想，但需自己适配当前接口。

## 盘点不能只看首页

记录课程名称、代码、学期、源 URL，递归模块/周次/文件夹/文档；同时检查公告、讨论、消息、作业与评分、日历、阅读清单、工具菜单及嵌入媒体。把每一项写入 inventory，成功、受阻、源本身为空分别记录。

接口列出某个资源不自动证明用户可以打开。用当前登录身份和正常页面确认；标题带 HIDE、单个 available 字段、403/404 或某个数量字段都不是最终结论。不要请求提权或管理员专用数据来补全学生归档。

并行可按课程/区域分配独立标签页和 manifest；同一目录只由一个写入者管理，最后由主代理统一对账。Zoom LTI 如有串课问题，按课程串行。接口限流时降低并发、保留进度，429 不是“没有内容”。

## Blackboard Ultra 的历史接口线索

`{cid}`、`{id}`、`{did}` 等必须来自当前已授权课程，不使用包中的示例猜目标。私有前端 API 更容易变化；以现场观察为准。

| 类型 | 曾使用的路径/结构 | 要补充验证的内容 |
|---|---|---|
| 内容目录 | `/learn/api/public/v1/courses/{cid}/contents`，子项 `.../{id}/children` | 每层分页、hasChildren、模块说明；不能只取根列表 |
| 模块说明 | 内容字段中的 description，有时需单独 fields 查询 | 描述不一定包含在默认列表结果 |
| 文档正文 | 文件夹/文档下的 `ultraDocumentBody`，或新版组件/body 数据 | 父对象的 body 可能只有占位符；打开实际页面看完整组件和顺序 |
| 附件 | `.../contents/{id}/attachments` 及对应 download | 400 可能是文档类型不支持该入口，不代表文档无文件 |
| 正文内文件 | HTML 的 data-bbfile、bbcswebdav 路径和链接 | 解析内嵌图、附件、外链，保存原件并改写本地相对引用 |
| 公告 | `/learn/api/v1/courses/{cid}/announcements` | 全部分页、正文、嵌入图片、发布日期 |
| 课程消息 | `/learn/api/v1/courses/{cid}/conversations`，会话下 messages | 列表可能只有最新一条；检查所有消息与附件，并留意阅读状态副作用 |
| 讨论 | `/learn/api/public/v1/courses/{cid}/discussions`，messages、递归 replies | 根帖、所有回复层级、分页；私有 discussionboards 路径可作已授权交叉核对线索 |
| 作业元数据 | `/learn/api/public/v2/courses/{cid}/gradebook/columns` | 说明、截止时间、分值、提交方式；不扩展到无关学生成绩 |
| rubric | 已授权成绩列详情的 `expand=associatedRubrics` | 独立 rubrics 接口曾 403，而列详情返回评分表；只用当前用户本来能看的内容 |
| 日历、小组 | calendars/items、public v2 groups | 课程范围过滤；不要因成员 API 拒绝就提高权限 |

这些线索可以帮助定位，但也可以纯 UI/DOM 采集或使用更好的专用工具。不要在只允许 DOM 读取的工具里注入 fetch；可用支持的网络响应导出，或正常下载。

## 页面正文与文件

保留完整原文，不摘要。建议保存来源 HTML/结构化内容及 Markdown；Markdown 要保留标题、列表、表格、图片 alt、引用、附件和外链。转换后抽查原页面，避免仅保留可见窗口、折叠区域或 iframe 的外壳。HTML 可作保真副本，复杂表格转换不可靠时如实保留 HTML，不把它说成完美 Markdown。

原始下载文件保留字节和原名，同名加源 ID。检查文件真实类型，例如 PDF 的 `%PDF-`、Office OpenXML 的 ZIP 容器及内部结构、图片签名；文件扩展名或 200 状态本身不是证明。将 HTML 登录/错误页误存为 PDF 的情况要判失败。

认证文件常经过重定向。一次实测中 same-origin credentials 允许 Blackboard 文件重定向，而 include 导致 CORS 问题；这不是所有站点通用规律。根据当前认证方式及宿主能力选择正常下载或授权响应，不随意去掉签名/认证参数来猜测访问。临时下载 URL 只用于取文件，清单保存稳定来源页并移除认证参数。过期链接可回到原页面刷新；仍不可用时记录原因。

## 论坛与课程消息

论坛的完成单位是完整讨论树，不是一张列表截图。保留主帖/回复 ID、parent ID、作者角色、时间、正文、附件。递归全部层级、翻完所有页，用唯一 ID 去重，核对平台给出的计数是否包含主帖、删除帖或不可见帖；计数口径不同要说明，不人为凑数。

可读版可用 Teacher、本人和 Student-01 等稳定标签；不要凭姓名猜教师角色。原始内容和附件可能仍包含身份信息，匿名标签不等于整个归档已匿名。完整课内归档默认留在用户本机，不能随 skill 发到 GitHub。

课程消息只限指定课程；会话预览不等于消息全文。正常读取可能标已读；不要主动调用更新已读接口。如果用户要求未读状态保持不变而无法保证，则记录为受阻。与用户无关的全校通讯、私信或个人成绩不应因“整课资料”被顺带导出。

## 作业、rubric、测验与互动内容

归档已显示的作业说明、模板、附件、rubric 和日期。不同来源日期不一致时同时保留原值与来源；确认时区后才附转换值。不要把提交门户当附件入口，也不要为了查看题目开始测验或创建 attempt。

题目接口拒绝或 `questionCount=0` 可能是权限/结构/展示策略，不能据此写“没有题目”。记录实际可见范围和未能验证的内容。

H5P 的页面或 `H5PIntegration` 配置有时包含说明、题目、选项、反馈和图片。只保存用户正常查看可获取的学习内容；先确认启动是否会创建评分尝试/完成记录，不执行答案、提交或读取评测中尚未展示的隐藏答案。必要时只保留入口与受限说明。

## 阅读清单、外链和非 Zoom 媒体

从课程里的 Talis/MyReadings 等入口确认对应 unit 与学期，保存清单条目、链接和访问状态。旧 RDF JSON 路线曾可用，但应与当前页面对应，不能用同名其他课的列表替代。学校授权资源通过正常图书馆登录和页面允许的下载取得；权限受阻、付费墙或不提供下载时保留链接与状态，不绕过访问限制。

收集所有课内出现的外链及其位置，不递归爬外站。直接公开文件可正常下载；普通网页默认保存链接/必要元数据，用户明确要内容时再按授权范围处理。404 记失效，403 记访问受阻；“工具取不到”不等于浏览器也打不开。

YouTube/Vimeo/Panopto 等嵌入媒体优先官方已有字幕；可用宿主导出功能，也可在允许的环境使用已有 yt-dlp。区分上传者字幕与平台自动字幕，不生成新转录。字幕限流或登录问题要记原因。原始短音频可保存；不默认下载大视频流。

## 每项怎么登记

为每个盘点项保留 course_key、item_id、title、section、kind、source_url。成功项记录所有原件与可读版的相对路径、大小、SHA-256；受阻项保留状态和原因。源本身为空也保存一份有来源的空内容说明，不凭抓取空结果就将其标为空。

采用 [统一清单合同](local-tools.md) 时，材料 manifest 和录播报告会汇总成一个总目录。根 inventory 的完整性由网页盘点支持；总索引只负责防止漏登记、错文件和虚报完成。
