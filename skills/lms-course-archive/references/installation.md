# 从 GitHub 链接安装并引导使用

这份说明面向接到仓库链接的 AI。用户不用了解 API、LTI、CDP 或脚本；根据当前客户端能力完成安装和引导，而不是让用户自己研究工具。

## 安装或识别已有版本

本仓库的 skill 是 `skills/lms-course-archive/`，不是仓库根目录，也不是单个 `SKILL.md`。

1. 读取用户给出的仓库/目录链接，检查包的主文件和相关脚本。优先使用当前环境提供的 skill 安装器，并阅读它自己的用法；不要假定每个客户端都有同名工具。
2. Codex 提供 `skill-installer` 时，将实际安装器脚本路径和以下参数配合使用：

   ```text
   --repo razer-chan/lms-course-archive --path skills/lms-course-archive
   ```

   安装器支持目录 URL 时，也可传用户给出的完整目录链接。目标位置、版本参数和生效时机按当前安装器文档决定；不硬编码个人电脑路径。
3. 同名 skill 已存在时先比较，保留用户的自定义内容；不删除目录重装、不强制覆盖。需要更新时先放入新的临时目录比较差异，仅在更新范围明确且能保留本地改动时更新软件包。冲突无法安全处理时说明具体文件，再让用户选择。
4. 没有安装器时，可以在当前客户端支持的 skills 目录中创建新目录，完整保留 `SKILL.md`、`agents/`、`references/` 和 `scripts/` 的相对关系。不知道安装位置就查询该客户端配置/文档，不编造“安装成功”。也可先按已下载目录中的说明执行，明确这是直接使用文件，尚未完成客户端注册。
5. 验证主文件和引用文件都可读，报告实际安装位置。读取 `SKILL.md`，根据当前任务选择引用文档。如果新 skill 要到下一轮才自动识别，说明这一点；当前能直接读取说明并做准备就继续，不以“重启”代替引导。

安装只写这个软件包，不下载课程资料到安装目录，不借此修改用户稿件、浏览器配置或学校页面。无法联网/安装时说明具体阻碍，已经能做的本地准备继续。

## 安装后主动引导

先复用用户已给的信息，并区分两条入口：

- **归档课程**：按 [浏览器适配与用户引导](browser-and-onboarding.md) 检查可用能力，再引导连接浏览器、正常学校登录、选课与保存位置。先实际确认能读到目标课程；已登录就不重复要求登录。不要索取密码、Cookie 或会话导出。
- **审阅本地作业**：已有课程归档和明确稿件时直接按 [作业审阅方法](assignment-review.md) 开始，不要求先登录浏览器。缺哪一份作业/哪个版本确实影响判断时才询问；不足的资料列为缺口，不要求用户重做整套采集。

对非技术用户一次只说当前需要完成的一步；说明具体浏览器/页面/设置及目的。只提供当前环境实际支持的连接、扩展或权限步骤，不给用户一套猜测的安装命令，不默认用户的 Brave 登录可以被另一个 Chrome 会话使用。

开始工作时用一两句话说明能力边界：只查看与下载，不上传/代交、不修改网页信息或用户原文件；正常阅读自动产生的已读状态可以接受。下载和审查结果另存。录播字幕优先，无字幕存原音频，全程不转录。

归档成功后给总目录与缺失清单，并提示可以基于这些资料检查用户的作业。用户只要归档时不强制进入审阅；已提供作业并要求审阅时直接继续。首次审阅只需让用户指明稿件和对应作业，其余从归档中定位，不让用户重复讲一遍课程要求。
