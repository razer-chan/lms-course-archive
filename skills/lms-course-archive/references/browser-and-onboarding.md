# 浏览器适配与用户引导

本 skill 提供归档方法和本地整理脚本，不附带浏览器控制器，也不会自动获得用户浏览器的登录状态。先查看宿主实际提供的工具和当前文档，再选择能完成任务的路线。工具名称、端点和选择器都可以替换；授权范围、内容完整性和真实落盘需要保留。

还未安装时先按 [安装与首次引导](installation.md) 处理。只审阅已有本地资料时不需要浏览器；需要补查最新公告或引用原文时只读访问，不能上传稿件换取在线校对、转换、查重或反馈。

## 对非技术用户怎样开始

先复用对话中已有的课程链接、浏览器、范围和保存位置。只有缺少会影响继续操作的信息时才问，一次处理一个缺口，不要求用户填写技术配置表。

| 当前情况 | 下一步 |
|---|---|
| 已有课程链接、用户说浏览器已登录 | 用宿主能连接的该浏览器打开工作标签页，核对课程名称与学期，然后继续；不要求重新登录 |
| 没有课程链接 | 先查看用户已指定或已授权查看的课程页面；仍无法确定时，再请用户提供课程链接或课程名称和学期 |
| 用户未指定浏览器 | 检查宿主现有会话，使用可访问目标课程的会话；只有需要用户选择时再询问 |
| 会话未登录或已失效 | 指明具体浏览器和页面，请用户完成学校正常登录、SSO、MFA 或验证码；返回后确认课程可见再继续 |
| 没有保存位置 | 在工作区使用独立归档目录，并告知实际位置；不要将课程资料放入 skill 或准备公开的仓库 |
| 没有浏览器控制能力 | 说明当前缺少的具体能力，按宿主实际支持的接入方式引导；也可让用户手动下载，AI 继续本地分类与核验 |

例如，课程已可访问时可以说：“我会检查这门课的全部分页和文件夹，保存资料与官方录播文字稿；没有字幕的场次保存录音，不做转录。最后给你总目录和未取得项目的清单。”

真正需要登录时只说明当前一步：“这个工作标签页停在学校登录页，请在这个页面完成登录；课程内容显示后我继续。”不要索取密码、Cookie、浏览器配置文件或让用户导出整个会话。也不要因某插件名称看起来合适，就声称它已安装或能控制指定浏览器。

用户授权了整课归档后，必要的只读查看和下载可继续进行，无须逐个文件重复确认。只要求材料、只要求录播或试跑时，保持该范围。课程身份不确定时先澄清，不抓取同名的另一门课。

## 能力选择与替代路线

| 任务 | 可用能力 | 使用界限 |
|---|---|---|
| 打开已登录课程、切换列表页 | 宿主浏览器连接器、Computer Use、受支持的浏览器自动化 | 实测目标课程可访问；不同浏览器或远程会话不自动共享登录 |
| 读取正文、链接、列表及字幕面板 | DOM、可访问性树、截图与普通界面操作 | 展开折叠区、分页和加载更多；滚动区域可能只渲染当前窗口 |
| 保存附件、字幕、音频 | 工具原生下载、网站下载按钮、原生另存为窗口 | 确认下载完成并找到实际文件；检查 HTML 登录页伪装成 PDF/VTT 等情况 |
| 读取页面已取得的响应 | 宿主明确支持的只读网络观察或 CDP Network 正文读取 | 只取当前授权页面实际加载的目标内容；按编码标志解码，等待正文可用 |
| 在已登录页面请求内容 | 宿主明确允许的页面脚本与 fetch | 仅用当前页面实际观察并核对的 URL；遵守请求、跨域和工具权限限制 |
| 将内容交给本地整理 | 原生文件产物、宿主文件工具、允许的本地脚本 | 确认文件在用户可访问的位置；隔离浏览器的下载目录不一定是用户本机 |

**当前 Codex CUA 的 `evaluate` 是只读 DOM 能力，不能在里面调用 `fetch`。** 能读取 DOM 不等于能注入本包的请求客户端。此环境应选择正常 UI 下载，或在当前工具文档确实允许时读取 CDP Network 响应。另一宿主如果明确支持页面 fetch，可以采用不同路线；不要把这条能力限制或某个成功经验当成所有宿主的固定规则。

字幕的响应读取、base64、完整音频范围和原生保存窗口经验见 [录播浏览器适配](recording-browser.md)。录播业务流程见 [录播完整流程](recordings.md)，普通附件和正文见 [材料采集经验](materials.md)。

## 登录、资源密码和页面副作用

课程登录与录播 passcode 是两层不同的正常访问流程。从已授权课程的 Zoom/LTI 入口进入，使用该场该资源实际显示的 passcode，在对应播放器表单里提交；遵守宿主的凭据操作要求。不猜密码、不跨场复用、不把密码写进来源、文件名、清单或共享包。如果密码确实缺失或学校要求用户完成 SSO/MFA，再交给用户处理当前阻碍。

正常阅读可能被网站记录为已读或学习进度，这类附带变化可以接受，不能承诺绝对零变化。不主动改完成/已读标志、发送消息、发帖或修改网页信息；不上传、提交、重交、撤回作业，不替用户勾选声明，不为查重或试验上传而创建草稿。测验、作业及 H5P 的“开始”“尝试”“提交”可能创建记录；它们不是下载步骤。提交入口只读核对可见说明和状态，不进入会创建尝试的流程。普通阅读清单和录播 LTI 可正常进入，但先核对用途，避免进入实时会议或启动考核。用户另有保留未读等要求时遵照执行。

## 平台变化与完整性检查

先以一个页面、一个附件和一场代表性录播验证当前路线，再批量处理。结构或响应改变时重新观察当前 UI、字段及实际请求，不继续猜旧端点。403、404、空列表、没有字幕卡或 `questionCount=0` 都不足以证明资源不存在。

记录当前日期过滤器和每页稳定身份，直到分页或加载更多确实结束，最后再复核。虚拟滚动列表与字幕面板可能只在 DOM 中保留少量可见行：优先完整官方下载或完整实际响应；用滚动采集时去重并证明首尾、计数与范围覆盖。拿到局部文本要保留未完成状态。

逐场检查所有片段和所需语言：一场的一份字幕成功不代表其他片段已经覆盖。默认每个片段优先官方字幕，确无官方字幕再保存原始音频。字幕存在但取不全属于受阻，不能改记为无字幕，也不自行转录补齐。面板只提供开始时间时保留实际开始时间，不推算 cue 结束时间。

## 可选 localhost 桥接：先判断是否适用

`capture_receiver.py` 和 `browser_capture.js` 仅在宿主同时允许页面脚本、页面 fetch 和本机通信时使用。它们是内容传递工具，不增加授权，不突破 CUA 的 evaluate 限制，也不绕过被禁止的请求或文件输出方式。能用原生下载时无需启动接收器。

启动时仅配置本次实际需要的精确 origin（协议、主机及可选端口，无路径、通配符或尾斜线），并使用进程新建的会话令牌。令牌文件放在归档目录外的私有运行目录，不打印、不提交到 Git、不交付。接收器只监听 `127.0.0.1`；来源许可和令牌共同限制本次写入。浏览器对某个站点的 localhost 许可不代表其他学校、Zoom 子域、浏览器配置或未来会话均已获准；换来源时重新核对实际能力与所需 origin，不要求用户一概点击所有“允许”。

所有写入结束后等待结果，调用 `await cap.close()` 或终止自己启动的进程。正常退出会移除令牌文件；强制退出可能留下临时文件，需私下清理且不要复用旧令牌。启动命令、客户端参数和限制见 [本地工具](local-tools.md#可选内容传递桥接)。

若某条路线不可用，说明具体缺失能力并换用允许的下载或本地整理方式。下载按钮被点击、文件名出现在界面、脚本报告成功，都不能代替文件大小、格式、哈希和逐项清单核对。
