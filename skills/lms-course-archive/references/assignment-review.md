# 基于课程证据的作业审阅

在用户要求检查稿件、理解教师期待或估分时使用。依据指定作业的正式规则、教师完整答疑和相关录播文字稿，交付可复核的诊断、适度的估分与优先事项。适用于论文、报告、作品集、演示等；按作品类型调整检查项，不套用某一课程的格式、理论数量或参考文献数量。

## 始终遵守的边界

- **课程网页只读。** 不上传、提交、重交、发帖、评论、发消息、修改网页资料或勾选声明；草稿查重入口也不上传。不开始测验或创建作业尝试。正常导航、展开和阅读引起的已读或访问记录可以接受，不主动改已读、完成或其他标志。
- **所有用户原文件保持原样。** 不编辑、重命名、删除、覆盖稿件、附件、课程归档或已有报告，不主动改变元数据、批注、修订和声明。即使其他流程写着“修复”“另存”“清理”，本模式也只在独立审查目录创建新的报告、证据摘录、提取物和工作副本；同名产物用新版本名。提取、渲染和原生应用检查都操作副本，防止自动保存碰到原件。普通读取可能更新系统访问时间，字节哈希验证不代表所有文件系统元数据都不变。
- **诊断不代写。** 不生成改写后的作业稿、替换段落、代填声明或可直接提交的分析答案。指出位置、问题、依据与修改方向，由用户自行修改。核对本作业实际 GenAI 规则及其适用用途；不假定“Level 2”等标签在各课程含义相同，也不凭工具名、文件作者属性或文风推断违规。
- **不进行任何新的转录。** 使用已有字幕或文字稿，优先官方来源；用户提供的非官方文字稿注明来源与核验状态，不能冒充教师确认文本。没有文字稿的原音频保留为证据缺口，不调用本地/云端 ASR、模型或转录服务，也不自行补写逐字稿。官方自动字幕仍可能有误，不能称为已校听原话。
- **估分是审阅判断。** 不承诺成绩，不把问题数量当扣分表，不把不确定事项自动变为失败。明确当前证据、假设和未核实部分。

下面八步是检查顺序，可按任务规模合并产物。要求核对、文件检查、引用核验可以独立进行，最终统一处理冲突，避免相互锚定。

## 1. 锁定稿件与证据范围

复用对话已有的课程、学期、作业名、稿件路径、用户时区、首审/复核和审阅范围。先从目录确认，只有无法确定目标稿件或课程身份时才询问，不能挑一份同名文件代替用户选择。

先读课程总目录、缺失清单及材料/录播 manifest，再盘点 brief、rubric、提交说明、template/scaffold、封面、Unit Outline、公告、课程消息、论坛、课件、模块、阅读及带分数范例。目录名称可能不同，按内容定位。记录每项来源、适用学期/作业、发布日期、采集日期、完整性及实际阅读状态。文件清单条数不等于已阅读数量。

确认 UA/coordinator、tutor 与 marker 的已知角色；不能凭姓名猜角色，也不能从教师名单推断用户分班。记录快照以后的信息未覆盖。需要补查时，只使用用户授权课程的正常只读入口及当前宿主允许的工具，遵循 [浏览器适配与用户引导](browser-and-onboarding.md)；没有能力就保留缺口。

在 skill、公开仓库和原稿目录之外新建独立审查目录。能读取文件字节时，计算原稿 SHA-256，制作字节一致的工作副本并记录其路径；交付前重新读取原稿核对。若哈希发生变化，记录变化并核实是否为用户同步编辑，不能自行还原或仍宣称“前后一致”。只有粘贴文本、附件阅读接口或无法落盘时，可直接在对话给报告，明确未做原文件字节校验及实际版面检查，不把缺少哈希工具当成所有内容诊断的阻碍。

## 2. 通读教师证据，建立小要求与许可清单

**先完整阅读相关讨论，再用搜索补漏。** 对目标作业问答区，读取主帖、全部分页、所有层级回复及相关附件；教师的短答复必须和原问题一起读。再检索其他讨论、公告和课程消息，并回到完整相关线程。不能把搜索命中或列表预览当成阅读了全部答疑。

录播先看逐场清单，标明官方字幕、官方面板文字稿、仅音频及缺失场次。通读所有与目标作业直接相关的讲解场次文字稿，包括解释、例子、评分演示及问答；截止前的场次也检查是否相关。其他场次可先按任务名和概念检索，命中后回读足够的前后上下文，直到能判断谈论对象、说话人、限制条件及后续更正。不能只读一句命中就作结论；无法通读或取得全文时明确写覆盖缺口。

检索可覆盖：word count/limit、included/excluded、rubric/marks、example/exemplar、must/should/prefer/can/not required、font/spacing/heading、reference/citation、declaration、deadline/attempt/resubmit，以及本课程特有的任务名、Part 和场景词。检索记录只是定位辅助，完整线程与场次上下文才是证据。

每条教师证据保存：

`短段逐字引文（原语言）｜原提问/上下文及适用对象｜中文解释｜说话人及已确认角色｜发言日期与原时区｜文件行号、页码或录播时间范围｜证据性质｜置信度/未核实点`

引用官方字幕时标注“官方字幕摘录”，记录是否校核；数字、否定词、术语、人名和说话人有疑点时与书面材料交叉核对。没有时间戳就使用文本行号，不编造时间；只有开始时间就不补结束时间。提供用户可点击的绝对文件路径及行号，或来源文件链接加时间戳/页码。不要把意译放进原话引号，也不要为凑证据而截掉限制条件。

单独交付“教师小要求与许可”表，覆盖实际找到的字数口径、标题、封面、声明、版式、引用、第一人称、结构、文件名、提交次数及期限等。不存在的规则不补造。

| 事项 | 逐字短引文与必要上下文 | 出处/定位、谁、何时 | 性质与适用范围 | 当前有效性/冲突 | 当前稿状态 |
|---|---|---|---|---|---|
| 实际发现的要求或许可 | 保留原语言，另附解释 | 可点击文件及行号/页码/时间 | 硬要求、强建议、偏好或许可 | 有效、已明确更正、待裁决 | 满足、不满足、不适用、待本人确认或无法验证 |

“must / should / prefer / can”是线索，不是自动分类器；结合权限、语境与正式规则判断。许可和“无需做”的说明同样保留，防止增加无用内容。旧说法保留更正链，不删除成看似从未出现。

## 3. 建立要求矩阵并处理冲突

不设“教师发言一律最高”或“最新材料一律覆盖旧材料”的总排序。分别判断：**是否针对本次作业、发言者有无该事项权限、是否明确修订、发布日期与有效期、原文完整性、当前系统状态**。正式 rubric 定义评分框架；教师解释帮助理解标准，不能悄悄新增评分项或改权重。

- 具有相应权限者对本任务作出的明确更正，可更新对应事项，记录旧规则、新规则及理由。只有较新日期、随口举例或某位 tutor 的偏好不足以证明正式要求改变。
- UA/coordinator、tutor、marker 的职责要核实。marker 偏好可以标作强信号，仍不能自动覆盖课程规定。书面与口头、brief 与系统设置不一致时，核对适用条件，不只按媒介定胜负。
- rubric 项目、满分或权重有明确修订时，注明版本；修订是否有效未能证实时，保留两种条件分析，不自行合并出一套权重。
- 本地 Markdown 与原始抓取不一致时，检查课程身份、时间、来源链、字段和内容完整性；`_raw` 也可能陈旧或抓取不全，不能因目录名就宣布它更权威。当前链接的旧学期附件可能仍适用，文件名本身既不能排除也不能确认它。空内容、零回复或不可见项不足以证明规则已撤销。
- 截止及宽限分别记录正式时间、时区、来源和换算结果。UTC 系统字段须先核实对应本次任务且未过期，再换算用户当地时间；夏令时与文字冲突不能靠猜测解决。提交次数的书面许可与界面设置不一致时，只读记录，不能尝试上传测试。
- 无法裁决时并列证据，说明哪项结论取决于哪种解释；低成本兼容方案标为“保守建议”，不能伪装成已确认规则。

要求矩阵至少记录：`事项｜适用要求/许可｜原文及定位｜性质｜冲突与判断理由｜当前稿证据｜状态｜置信度`。把 rubric 各项名称、权重、实际档位描述与边界保留在证据记录里。通用写作规范仅按课程采用的规范补充，不强制 APA、固定模板、目录、引言/结论、理论数或参考文献数。

声明检查先确认**已经存在的内容**、位置、适用规则和更新解释。封面已有声明时，不能写“没有声明”；是否还需文末重复、补充用途或更换位置，必须分别核实。未勾选项、身份、实际工具用途只列待本人如实确认，不能替勾或自动推断违规、零分、封顶。

## 4. 阅读完整稿件并检查文件与字数

以工作副本提取正文、表格、文本框、脚注/尾注、页眉页脚、图注、附录等，避免只读取普通段落漏内容。检查文件可打开、图片与链接、占位符、批注、修订及隐藏文字；封面勾选状态用渲染或实际结构核实，不能从纯文本猜测。文件属性或工具署名只描述观察，不作为作者身份或学术诚信结论。

需要版面审查时，在审查目录渲染副本并逐页查看；可用原生应用只读检查副本交叉验证。说明使用的渲染器、字体替代、实看页数及限制。转换后的分页差异不直接算原稿错误，缓存的 Words/Pages 不是实时统计。检查失败就写“尚未验证版面”，不能拿 XML 检查代替逐页观看。

格式检查按已证实要求判断，包括文件名/格式、封面、纸张/方向、字体/行距/缩进、标题与分页、图表/页码/引用等。官方模板自带 logo、颜色或示例占位标记要区分；没有硬规则的可读性改善标为建议。图片问题要区分内容、展示尺寸、分辨率与来源，不能看到小图就认定像素不足。

**字数先确定范围，再计数。** 列清正文、标题、直接引述、文内引用、图题/图注、表格、附录、场景原文、参考文献和声明的计入规则；未知部分单列。按课程指定方法统计；未指定时可用原生应用对实际计入区段计数，脚本结果注明算法。不要拿全文总数判超限，不机械删掉所有引号文字或把孤立标点当词。

给出分区字数、口径、总数、距上下限余量及未决口径下的条件结果。建议的分段长度不自动变为硬上限。超字后果只有明确依据时才写；不同计数方式的差异先排查，不以少量偏差夸大问题。

## 5. 按 rubric 审阅内容并校准

每项将**正式档位描述 + 教师相关解释 + 稿件原文证据**对应起来，用章节、页码和短原文定位。说明已达到的特点、尚不足的特点，以及阻挡上一档的具体因素。页码随版本变化，原文短语要同时保留。

按本作业实际目标检查：是否回答各部分、中心论点与段落是否衔接、理论是否用于分析具体情景、建议是否解释机制与可行条件、评价是否比较证据并识别局限。避免以“理论少”代替论证诊断；不能因为标题含 reflective 就要求日记或虚构个人经历。

特别核对：与给定事实矛盾、把推断当观察、概念/术语/计算错误、绝对化结论、因果与相关混淆、群体结论套到个人、跨年龄/国家/学科外推，以及“研究支持”是否只是在句尾贴引用。课程正在使用的理论不能仅因外部争议被判错误；指出争议须说明与任务的相关性和适用边界。

有带分数范例或课堂 marking example 时，核实课程、任务、rubric 版本及真实评分来源，比较分析深度、连贯性、情景联系和证据使用。不同老师对同一例子的评分差异也是不确定性，不取最高者当承诺。范例中的错误不变成标准，流畅也不等于高分；旧 AI 报告仅可作线索。

明确保留优点和“不需要改”的内容；没有依据时，不要求增加目录、长结论、额外理论、引用或个人故事。复核时允许撤回先前误报，不能为维护旧判断继续要求修改。

## 6. 分开核验文献存在性与论点支持

双向核对每条文内引用和参考文献，检查作者、年份、同年后缀、直接引文位置及课程指定格式。按明确规则才统计来源数量、年限或同行评审类型；经典文献不因较旧自动扣分，额外来源也不能替代指定来源。

| 核验层 | 需核对的内容 | 不能推出的结论 |
|---|---|---|
| 存在性与元数据 | DOI、作者、题目、出版物、年份、卷期页码；书籍版本/译者/原版年份 | 找到 DOI 不等于论文支持稿件论断 |
| 内容支持与适用性 | 对应页段、原句语境、研究对象/设计/结论强度，是否支持当前外推 | 摘要或局部原文不能称作已核实全文 |
| 链接与媒体可用性 | 实际目标内容、资源身份，必要时检查页面中的媒体入口 | HTTP 成功或页面可见不等于全部音频/视频完整可用 |

用已授权本地资料及适用的官方数据库、出版社或原始来源核查；不能取得全文时明确写“仅元数据”“仅摘要”“相关页段”或“未验证”。403/429、脚本抓取失败不等于文献不存在，现行网页失效也不自动否定正确的存档引用。图注来源要对应实际图片，并区分网站承载、版权与文化知识权威等不同主张。

引用规则以课程采用的规范及其正式指南为依据；只说明真实缺项，不为显得严谨追加未经证实的许可或声明。不得把稿件上传查重、AI 检测或第三方处理网站来完成核查，也不声称存在通用“安全相似率”。

## 7. 公平估分，给出条件与置信度

有可用 rubric 及评分尺度时，**先定该项档位，再判断档内位置，最后按实际权重或该项满分计算**。列出每项权重、档位、估计、原稿证据、尚欠条件和置信度；复核总和。总分、作业满分和课程总评占比要区分，不重复乘权重。

中心估计、区间和档位仅在证据支持时提供。区间宽度由证据完整性、档位边界、教师尺度差异及未决冲突解释，不固定为某个正负分数；HD 等标签及分界从本课程取，不跨校沿用。允许结论跨档，避免虚假小数精度。

同一缺陷可能影响多项，但须说明不同评分维度，不把同一问题重复减分；格式若已包含在 writing 中，不另造格式扣分。迟交、声明、诚信或相似率没有核实和明确适用规则时，不估算惩罚，分别列为未纳入因素。审阅优先级不是分值，也不按发现多少问题机械压低总分。

缺 rubric、缺权重或尺度时，先寻找本任务明确适用的正式评分依据；仍缺失则只做定性质量诊断、列出估分所缺资料，**不自行编造标准、权重、分数或档位**。有 rubric 但缺范例可按 rubric 审阅并说明校准限制；无字幕、论坛不全、旧快照等缺口须反映到相关判断的置信度。

## 8. 交付、优先事项与复核

报告用用户语言，教师与稿件引文保留原语言。按规模合并成一份报告及必要附件，避免只有工具日志。至少包括：

1. 审查对象、版本、日期、证据快照、只读边界与实际检查范围。
2. 核心优点、主要问题、估分或不能估分的原因，以及假设/置信度。
3. rubric 分项判断与计算、官方要求矩阵、教师小要求与许可清单、冲突记录。
4. 字数口径、文件/版面检查、引用两层核验及未覆盖事项。
5. 按优先级排列的建议与已通过、无需改变的部分。

每条建议写：`位置（部分 + 页码 + 原文短语）｜发现与性质｜证据/对应 rubric｜影响与不确定性｜用户自行修改的方向｜完成标准｜可能的字数代价`。性质至少区分已确认要求、教师偏好、推断、建议与证据缺口。

优先级按当前证据确定，可用下面标签；没有相应问题就不设该类：

| 级别 | 使用条件 |
|---|---|
| P0 已确认的阻碍 | 已确认且适用于本任务的规则，结合当前稿证据，确有不被评阅或其他明确后果；必须附原文和判断条件 |
| P1 主要质量问题 | 对高权重标准、中心论证或关键事实有实质影响 |
| P2 精度与表达 | 支持强度、引用定位、表述或可读性等局部问题，按实际影响排序 |
| P3 可选完善 | 有益但不是本课程已确认要求的改进 |
| 待确认 | 规则、稿件状态或本人实际情况不足，先说明条件，不冒充 P0 |
