# LMS Course Archive · 课程归档与作业审阅

**复制下面三行，直接发给 Codex。** 它会读取仓库说明，安装 skill，并按需引导你配置浏览器和登录。

```text
https://github.com/razer-chan/lms-course-archive/tree/main/skills/lms-course-archive
请安装并使用这个 skill，引导我登录并归档指定课程的资料和录播。
之后结合这些资料，只读检查我提供的作业，给出中肯估分和优先修改建议。
```

## 这个 skill 做什么

把课程里你能访问的资料保存到电脑，按课程和周次分好类。包括页面、PDF/PPT、附件、作业说明、rubric、公告、论坛及全部回复、阅读清单，以及 Zoom 云录播的官方字幕和 TXT。

有作业稿件时，还能结合这些资料检查内容、引用、排版和提交要求，提供分项估分、教师补充要求及优先修改清单。可以单独使用审阅功能，不必重新抓课。

**录播默认优先官方字幕；没有字幕就保存原始录音，不进行任何新的转录。** 不需要转录模型或 GPU。它是一份给 AI 使用的工作流和本地工具箱，AI 会根据当前学校页面和自己的工具进行适配。

## 安装后怎么用

直接告诉 Codex 课程链接，或提供已有课程资料与待审稿件。例如：

```text
使用 $lms-course-archive，保存这门课的全部资料和录播：[课程链接]。
```

已有资料时可以说：“使用 $lms-course-archive，结合这个课程目录检查这份作业，只给审阅报告。”也可以只抓录播、只抓材料或先做少量试跑。已有信息不用重复；详细安装步骤和浏览器引导都在 skill 内。

## 使用边界

- **不上传或代交作业，不改网页信息。** 不进入上传、草稿查重、提交/重交/撤回、测验尝试等流程，不发帖或发消息，不替你填声明、勾选承诺或更改设置。也不把稿件上传到外部校对或转换服务。
- **不修改你提供或上传的原文件。** 不编辑、覆盖、改名、移动、删除或写入批注，不生成改写后的作业。下载副本、提取/渲染副本、清单和审阅报告另存到独立输出目录；只更新本任务自己的进度文件，不覆盖你的现有文件。
- **正常阅读的附带状态变化可以接受。** 公告自动变已读、页面自动记录访问不属于主动编辑；不会主动点击“标记已读/完成”。
- **不进行转录。** 只有音频的场次原样保存，相关审阅证据列为缺口。
- **估分有条件，不是教师成绩。** 正式要求、教师偏好、推断和建议分别说明；讲清来源、核验程度、缺失资料和估分假设，不保证成绩，也不把建议当作必须扣分的规则。

这些是本 skill 的工作范围；没有修改稿件或代交模式。它是一套给 AI 执行的流程，不是能从技术上锁住所有工具的权限沙箱，仍需要宿主正确执行边界。

## 从开始到结束的流程

1. **安装与检查环境**：Codex 安装 skill，检查浏览器和文件保存能力。需要你配置连接或权限时，告诉你具体点哪里。
2. **登录与选课**：你完成学校正常登录和验证，提供课程链接；Codex 确认自己确实能看到目标课程。
3. **小样本验证**：先检查一页正文、一个附件或一场录播，确认当前网站结构及保存方式可用。你也可以要求只做这一步。
4. **建立完整目录**：递归模块、周次和文件夹，翻完分页，盘点公告、论坛回复、阅读清单和每场录播的所有片段。
5. **分别采集**：材料保存完整正文和原附件；论坛保留回复关系；录播保存官方字幕和 TXT，没有字幕则保存原始音频。
6. **核验与补漏**：核对清单、文件类型、大小和哈希，再复核网页目录。中断后可以续跑，相同内容复用，冲突不覆盖。
7. **交付归档**：生成一个本地总目录，汇总材料和录播。没取得的项目保留原因，不把失败或只抓到部分内容写成完成。
8. **按需审阅作业**：你提供稿件后，AI 阅读目标作业的要求、rubric、教师问答和相关字幕，核查内容、引用与实际文件，再独立输出估分及修改建议。你自行改好后可再复核。

过程中你可以继续使用其他标签页，保留工作页和登录状态即可。需要你操作时，Codex 应一次说清一件事；其余盘点、命名、整理和校验由它处理。

安装 skill **不会自动赋予浏览器访问权限**。Codex/其他 AI 需要当前环境支持的浏览器工具或 Computer Use，以及可写的文件空间。若没有，AI 应说明缺哪项能力并按宿主支持的方式引导配置；仅有聊天和附件阅读功能的环境不能自动下载登录后的课程。

## 下载范围

| 内容 | 默认处理 |
|---|---|
| 课程页面、模块与周次 | 完整正文和来源，保留结构，整理成可读文件 |
| PDF/PPT/Word/图片等附件 | 原始文件，验证类型、大小和哈希 |
| 作业说明、rubric、日历等 | 保存用户有权查看的说明与元数据，不开始测验或提交 |
| 公告、课程消息、论坛 | 课程范围内正文、附件、全部分页与回复关系；说明已读状态等限制 |
| 阅读清单、外链、嵌入内容 | 保存清单和可合法取得的资料，受限内容保留链接及状态 |
| Zoom Cloud Recordings | 官方字幕原件 + TXT；无字幕时保存原始音频 |
| 作业审阅 | 按需基于课程证据只读检查；报告中区分要求、推断、建议与缺口 |
| 转录、归档原文改写 | 不执行；审阅报告的分析另存，原资料不改 |
| 发布、发帖、作业提交 | 不执行 |

平台可能自动记录正常阅读行为；skill 不主动更改已读/完成标志。课程归档用于用户本地使用，实际课程资料、学生信息、密码和会话不会进入这个工具仓库。

## 作业怎样检查

先盘点资料与缺口，再阅读目标作业的完整要求、教师问答及相关官方字幕；老师的特殊要求、偏好和许可附短引文、上下文与出处。证据有冲突时，结合适用作业、发言者权限、日期和明确更正判断，不机械地让口头话覆盖评分表。

审阅结合实际 rubric 检查论证与课程知识、文献是否支持具体论点、图片链接及最终版面，并按本课口径统计字数。评分使用本次 rubric 的权重和档位，区间随证据质量变化；不固定引用体例、学科结构、HD 门槛或处罚。资料不足以评分时先给诊断，说明缺什么。

最终说明做得好的部分、影响分数的主要差距，以及每条建议的位置、依据、条件和完成标准。提交条件与学术表现分开判断；复核不沿用旧字数和旧分数。详细方法见 [作业审阅流程](skills/lms-course-archive/references/assignment-review.md)。

## 最后会得到什么

打开归档目录里的 **`00_总目录_README.md`**，就能按课程和分类找到文件。下面是示意结构，不是真实课程数据；分区和文件名会随课程内容调整。

```text
课程归档/
├── 00_总目录_README.md            从这里开始，点击进入各类资料
├── 下载清单.csv                   用 Excel 查看每项来源、路径和状态
├── 归档清单.json                  供 AI 续跑、核验和后续整理
├── 未完成与缺失.md                没拿到什么、为什么、需要怎样处理
└── UNIT101-学期/
    ├── 01_课程信息/
    ├── 02_公告与课程消息/
    ├── 03_导览/
    ├── 04_作业与评分/              作业说明、模板、rubric
    ├── 05_模块或周次/              按课程原顺序整理正文及附件
    ├── 06_工作坊课件/
    ├── 07_讨论区/                  主帖、所有回复和附件
    ├── 08_Recordings/
    │   ├── recordings.md           逐场录播清单与文件链接
    │   ├── recordings.csv
    │   ├── recordings.json
    │   └── 课程标识/日期/场次/片段/
    │       ├── official.vtt        或官方 SRT / TXT
    │       ├── transcript.txt      可读字幕，保留原文与时间戳
    │       └── audio.m4a           无字幕时的原音频，格式可能不同
    ├── 09_阅读清单/
    ├── 10_媒体与外链/
    ├── _raw/                      保留用于追溯的内容数据，排除认证凭据
    └── _工作记录/                  盘点、采集进度和材料清单

独立审查输出/                        按作业和版本新建，不改上面的归档或原稿
├── 审查报告.md                     结论、分项估分、条件、优点、优先修改清单
├── 教师要求与许可.md                原话、上下文、出处和当前稿状态；可合并进报告
└── _工作文件/                      哈希记录、提取文本、渲染副本、证据核查
```

同一录播片段默认保存“官方字幕 + TXT”或“原始音频”，上面的文件名展示可能的产物，并不表示每场都会下载三种文件。官方直接提供 TXT 时保留原 TXT；从完整字幕面板导出时还可保存 `official-cues.json`，不捏造结束时间。

| 你拿到的结果 | 怎么用 |
|---|---|
| 原始 PDF / PPT / Word / 图片 | 用平时的软件直接打开，保留原文件内容 |
| 页面 HTML / Markdown | 离线阅读完整正文，查看附件和来源链接 |
| 论坛可读文件 | 按主帖和回复关系查阅，保留时间与附件关联 |
| 官方 VTT / SRT / TXT | 保留平台发布的字幕；TXT 方便搜索或交给 AI 阅读 |
| 原始音频 | 无字幕时仍保留录音，skill 不对其做转录 |
| 总目录与清单 | 查成功项、待处理项、受限链接及核验情况 |
| 作业审查报告 | 看分项估分、主要差距、优先修改建议及尚未核实的条件 |
| 教师要求与许可表 | 回查短引文、时间戳或页码，区分必须、建议、偏好及允许事项 |

结束时 Codex 会给出实际保存位置和数量，例如页面、附件、讨论帖子、官方字幕场次、音频回退场次，以及仍未完成的项目。数量来自清单；有缺口就明确说明，不用一句“完成了”掩盖。

## 需要的软件

- 浏览器操作能力和本地文件空间：自动采集需要，由使用者的 AI 环境提供。
- Python 3.10+：使用随包本地脚本时需要；全部是标准库，没有 pip 依赖。AI 也可采用自己的等价实现。
- 文档读取/渲染工具：审阅 Word、PDF、幻灯片等时按文件类型选用当前可用工具；不绑定 Microsoft Word，也不要求上传到在线转换网站。无法验证版面或精确字数时明确说明。
- ffprobe：可选，只用来验证音频容器和时长；没有时报告校验范围。
- yt-dlp：可选，只在处理适用平台的已有字幕时使用；不要求为此安装，也不作为 Zoom 必需条件。
- 不需要学校管理员账号、Zoom 管理员 API key、Whisper/MacWhisper、云转录服务或模型文件。

## Skill 本身的结构

```text
skills/lms-course-archive/
  SKILL.md                         主流程与用户引导
  agents/openai.yaml               Codex 显示信息
  references/
    installation.md               从仓库安装、识别更新与首次引导
    browser-and-onboarding.md     浏览器能力、登录和页面边界
    assignment-review.md          通用作业审阅、估分、报告与复核
    materials.md / recordings.md  材料与录播主流程，按需读取其余技术参考
  scripts/
    recording_archive.py           字幕/TXT/音频整理与逐场校验
    build_course_index.py          材料与录播统一索引
    capture_receiver.py            可选本机接收器
    browser_capture.js             可选、显式启用的浏览器采集辅助
tests/                             纯合成/本机测试，不含真实课程内容
docs/                              发布说明、实现边界和验证记录
```

本机接收器仅适用于宿主允许页面脚本与本机通信的环境；普通下载或工具原生产物输出通常更直接。当前工具若只允许 DOM 读取，AI 应用正常 UI/下载或受支持的网络响应读取，不使用桥接脚本规避限制。

## 兼容性与验证

流程来自 Blackboard Ultra / SCU 实际工作，接口、按钮和媒体结构会变化。包里保存的是思路和故障处理经验，不要求照抄旧地址。其他 LMS 和 AI 客户端需要按现场能力适配，不能保证一次适配覆盖所有学校。

具体实测范围见 [验证记录](docs/VALIDATION.md)，开发与本地测试见 [开发说明](docs/DEVELOPMENT.md)。
